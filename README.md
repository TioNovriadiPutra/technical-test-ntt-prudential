# Technical Test - NTT Prudential

A modern product management application built with React, TypeScript, and Vite. This project demonstrates product listing, searching, creation, and editing functionalities using the DummyJSON API.

## Features
- Product listing with pagination
- Product search with debounce
- Product detail view
- Create new product
- Edit existing product
- Form validation with React Hook Form
- State management with Zustand
- API integration using Axios
- Data fetching and caching with TanStack Query

## Tech Stack
- React 19
- TypeScript
- Vite
- React Router
- React Hook Form
- Zustand
- Axios
- TanStack Query
- Tailwind CSS
- Motion.dev

## Getting Started

### Prerequisites
- Node.js 20+
- npm or yarn

### Installation
Clone the repository:
```bash
git clone https://github.com/TioNovriadiPutra/technical-test-ntt-prudential.git
```

Move into the project directory:
```bash
cd technical-test-ntt-prudential
```

Install dependencies:
```bash
npm install
```

### Running the Project

Start the development server:
```bash
npm run dev
```

The application will be available at:
```bash
http://localhost:5173
```
